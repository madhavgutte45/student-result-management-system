# 🎓 Student Result Management System

A simple console-based Student Result Management System built using Python.

## 🚀 Features

- Add student details and marks
- Calculate total marks
- Calculate percentage
- Automatically assign grades
- Display all student results
- Search students using roll number

## 🛠️ Technologies Used

- Python
- Lists
- Dictionaries
- Functions
- Loops
- Conditional Statements

## 📌 Project Overview

This project was developed to practice Python programming fundamentals and basic data management. It demonstrates the use of functions, lists, dictionaries, loops, and conditional statements to manage student results.

## ▶️ How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project in a Python IDE.
4. Run `student_result_management.py`.
